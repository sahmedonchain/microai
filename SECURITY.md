# Security policy

MicroAI is experimental and has not been independently audited.

## Reporting a vulnerability

Please report security issues privately with GitHub's Private Vulnerability Reporting:

**https://github.com/sahmedonchain/microai/security/advisories/new**

Do not open a public issue or pull request for a vulnerability, and do not test against other users' wallets or funds.

Helpful details: what you found, where (page, API route or file), steps to reproduce, and the impact you see.

## Scope

The live app at https://microai-tan.vercel.app and the code in this repository.
